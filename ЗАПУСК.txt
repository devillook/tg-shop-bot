BETA — магазин аккаунтов

1. Открой файл .env (Блокнотом): впиши BOT_TOKEN, API_HASH, и SUB_CHANNEL (канал без @, например codcrytg).
   ВАЖНО: бота нужно добавить в этот канал (лучше администратором) — без этого проверка подписки
   не будет работать и бот может заблокировать вообще всех.
2. Дважды кликни 1_УСТАНОВКА.bat (один раз).
3. Дважды кликни 2_ВХОД_В_СВОЙ_АККАУНТ.bat и войди в аккаунт @jonnkq (один раз).
4. Дважды кликни 4_ЗАПУСК_БОТА.bat. Окно не закрывай — там видно все события.
5. Дальше ВСЁ остальное делается прямо в боте, в "🛠 Админ-панель":
   - "📲 Войти в аккаунт" — настоящий вход по номеру+коду (как раньше через консоль), после этого
     код при входе покупателя бот ловит и отправляет сам, плюс копию — тебе.
   - "➕ Добавить вручную" — просто карточка без входа, для аккаунтов, в которые сам зайти не можешь.

Команды администратора (пиши прямо боту):
  /stock                         — склад
  /setprice ID ЗВЁЗДЫ            — изменить цену
  /remove ID                     — снять с продажи
  /getcode ID                    — вручную вытащить код (для synced-аккаунта), переслать через /sms
  /addbalance ID СУММА           — начислить/списать токены пользователю
  /newpromo КОД СУММА [ЛИМИТ]    — создать промокод (лимит по умолчанию 1)
  /sms ID ТЕКСТ                  — личное сообщение пользователю
  /support ID ТЕКСТ              — ответ на обращение в поддержку

Как работает автовыдача кода: когда покупатель, оплативший "синхронизированный" аккаунт (вошли через
"📲 Войти в аккаунт"), начинает вход в Telegram и Telegram присылает код — бот сам ловит этот код
в служебном чате аккаунта и сразу пересылает: покупателю в бот, и тебе на основной аккаунт.
Привязка строго по текущему оплаченному заказу на этот аккаунт — чужому код не уйдёт.

Реферальная программа: у каждого пользователя в "Мой кабинет" есть личная ссылка. Когда приглашённый
по ней человек нажимает /start в первый раз — пригласившему начисляется REFERRAL_BONUS_TOKENS токенов.

Перед настоящими продажами в .env поставь BETA_MODE=0.
Никому не отправляй файлы .env и папку sessions.
